# 从零构建本项目 · 文件写作顺序（bottom-up,下层先写）

## 阶段一 地基 core
1. `app/core/config.py`   配置(后端可切:embed/llm 的 stub/hf/openai)
2. `app/core/logging.py`  结构化日志
3. `app/core/exceptions.py` 自定义异常 + 全局处理

## 阶段二 契约 schemas
4. `app/schemas/kb.py`    请求/响应 pydantic

## 阶段三 服务 services（按内部依赖排）
5. `docparse.py` 文档解析   6. `chunk.py` 切块   7. `embedding.py` 嵌入(stub/hf)
8. `index.py` 向量库   9. `rerank.py` 重排   10. `llm.py` LLM(stub/mlx/openai)
11. `rag.py` 编排(依赖 5-10)   12. `agent.py` 路由(依赖 rag)   13. `cache.py`

## 阶段四 接口 routers
14. `health.py`   15. `documents.py`(依赖 rag)   16. `query.py`(依赖 agent+cache)

## 阶段五 组装 + 前端 + 运维 + 测试
17. `main.py`(组装) 18. `static/index.html` 19. `run.py`
20. `tests/`(stub 后端离线测) 21. `Dockerfile`/`docker-compose.yml`/`.env.example`

> 原则:上层 import 下层 → 下层先写。外部依赖(嵌入/LLM)抽象成"后端",默认 stub 让测试离线。
