## ② 按主题速答（散落在各案例里的一句话速答，已归类 + 标出处）

### 基础 / 推理（Ch1-3）
- **为什么模型只输出 logits？** 交叉熵训练内部自带 softmax，数值更稳；推理时才手动 softmax。〔`分章项目/Ch1_情感分析服务.py`〕
- **greedy / beam / sampling 各适合什么？** 确定性任务→greedy；有「正确答案」的翻译摘要→beam；要创造性→sampling。〔`分章项目/Ch1_进阶_生成与采样.py`〕
- **top_k vs top_p？怎么治复读机？** top_k 固定候选数、top_p 按累计概率动态截断（最常用）；复读用 repetition_penalty / no_repeat_ngram_size。〔`分章项目/Ch1_进阶_生成与采样.py`〕
- **MLM vs CLM？AutoModel vs AutoModelForX？** 双向遮词填空 vs 单向预测下一词；后者带任务头。〔`分章项目/Ch3_预训练模型应用.py`〕

### 微调 / 训练工程（Ch2, 11）
- **动态填充比固定 max_length 好在哪？** 只补到当前 batch 最长，省无效计算/显存。〔`分章项目/Ch2_文本分类微调.py`〕
- **Trainer vs 自定义循环？compute_metrics 干嘛？** 标准微调用 Trainer；要插自定义逻辑用 Accelerate。〔`分章项目/Ch2_文本分类微调.py`〕
- **Accelerate 核心 API？适配器为什么能分离部署？QLoRA vs LoRA？** prepare/backward 三件套；适配器是旁挂低秩增量，可与基座分开存/加载；QLoRA 多一步 4-bit 量化基座。〔`分章项目/Ch11_进阶_训练工程.py`〕
- **LoRA 原理？r/alpha/target_modules？为什么用聊天模板不手拼？** 冻结基座只训低秩对；模板各家不同、手拼易错。〔`分章项目/Ch11_LoRA指令微调.py`〕

### 分词器（Ch6）
- **领域词被切碎怎么办？BPE/WordPiece/Unigram 区别？offset_mapping 有什么用？** 领域重训分词器；三算法合并/删除策略不同；offset 把 token 结果贴回原文。〔`分章项目/Ch6_领域分词器.py`〕
- **三算法训练与编码怎么做？WordPiece 打分为什么除以左右频？** 见手写实现。〔`分章项目/Ch6_进阶_手写分词算法.py`〕

### NER / 四大任务（Ch7）
- **aggregation_strategy 有什么用？NER 里 -100 标签干嘛？子词怎么拼回实体？** 合并子词成实体；-100 让填充/子词非首位不计损失。〔`分章项目/Ch7_NER实体识别.py`〕
- **抽取式QA 预测什么？困惑度是什么？BLEU/ROUGE 分别衡量什么？** 预测答案起止位置；PPL 衡量语言模型；BLEU 看精确率、ROUGE 看召回。〔`分章项目/Ch7_进阶_四大NLP任务.py`〕

### RAG / 检索（Ch5-6）
- **为什么用向量+余弦不用关键词？句向量为什么 mean 要用 mask？FAISS 解决什么？** 语义相近向量相近；mask 避免 [PAD] 稀释；FAISS 做大规模近似最近邻。〔`分章项目/Ch5_语义搜索引擎.py`〕
- **为什么召回+重排两段？** 召回快扫全库（双塔向量），重排准（cross-encoder 精排 top-N）。〔`综合项目/项目5_电商语义搜索.py`〕

### 上线（Ch9）
- **Interface vs Blocks 怎么选？Gradio 怎么快速上线/自动出 API？** 快速原型 Interface、灵活布局 Blocks；launch 自带 API。〔`分章项目/Ch9_Gradio应用.py`〕
- **gr.State 解决什么？流式怎么做？怎么把 Gradio 挂到已有 FastAPI？** 多轮会话状态；yield 流式；mount_gradio_app。〔`分章项目/Ch9_进阶_生产化.py`〕

### RLHF / GRPO（Ch12）
- **GRPO vs PPO？优势怎么算？为什么组内要有方差？为什么用可验证奖励？** 去掉 critic 用组内相对优势；(r-均值)/标准差；全对全错无信号；可验证奖励最可靠。〔`分章项目/Ch12_GRPO强化学习.py`〕

### 中文特化（面试常追问）
- **为什么不能用英文模型跑中文？** 模型只认训练过的语种/词表，跨语言失准。〔`中文版/中文_情感分析.py`〕
- **中文检索为什么不用英文嵌入？** 语义空间不对齐，要用 bge/text2vec 等中文嵌入。〔`中文版/中文_语义检索RAG.py`〕
- **中文 NER 和英文不同在哪？** 常逐字标注要拼回词、类型体系不同（CLUENER 10 类）。〔`中文版/中文_NER实体识别.py`〕
- **做中文 NLP 系统模型怎么选？** 情感→中文点评微调；检索→bge-zh/text2vec；NER→CLUENER/UIE；生成→Qwen/GLM。〔`中文版/中文_智能客服全流程.py`〕

### Agent（smolagents / 框架）
- **Agent 靠什么决定调哪个工具？** 工具的 name + description + 参数类型（inputSchema）。〔`Agent实战/案例2_NLP能力Agent_中文客服.py`〕
- **Agentic RAG 和普通 RAG 区别？** 普通 RAG 固定检索一次；Agentic 让 LLM 自己决定查什么/查几次/够不够。〔`Agent实战/案例3_Agentic_RAG_中文知识库.py`〕
- **Agent 为什么要用 MCP（不把工具写死）？** 即插即用/热插拔、跨进程跨团队复用。〔`Agent实战/案例4_Agent接MCP工具.py`〕
- **三框架怎么选？** 快速/代码任务→smolagents；复杂可控流程→LangGraph；数据 RAG 重→LlamaIndex。〔`Agent实战/案例5_多框架对比…py`〕

### MCP 协议
- **能力协商为什么取交集？通知和请求怎么区分？Roots/Sampling 方向有何不同？** 双方只用都支持的能力；通知无 id 不回复；Roots/Sampling 是 server→client 反向。〔`mcp实战/案例7_MCP协议进阶…py`〕
- **FastMCP 和手写 JSON-RPC 关系？** 同一套 MCP 消息，FastMCP 是官方封装（装饰器自动生成 schema）。〔`mcp实战/案例6_FastMCP官方SDK生产版.py`〕
- **Gradio 怎么一键成 MCP 服务器？生产里 Host 端怎么连 MCP？** launch(mcp_server=True)；用官方 SDK Client 不手写 subprocess。〔`mcp实战/案例8_GradioMCP与官方SDK客户端.py`〕
