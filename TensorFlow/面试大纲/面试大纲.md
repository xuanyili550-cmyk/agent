## 一、Transformer / 基础（Ch1-2）

**Q1. pipeline 一行代码内部做了什么？**
三步：①分词器把文本转 input_ids/attention_mask ②模型前向输出 logits ③后处理(softmax→概率、argmax→标签)。所以 pipeline = tokenizer + model + 后处理。

**Q2. attention_mask 是干嘛的？不给会怎样？**
标记哪些是真实 token(1)、哪些是填充 [PAD](0)，让注意力忽略填充位。不给的话，补齐的 [PAD] 会参与注意力计算、污染结果——同一句单独跑 vs 放进补齐的 batch 里跑，logits 会不同。

**Q3. logits 和 softmax 的关系？为什么模型只输出 logits？**
logits 是最后一层未归一化的分数(任意实数)。softmax 把它变成 [0,1] 且和为 1 的概率。模型输出 logits 是因为训练用的交叉熵损失内部自带 softmax(log_softmax)，数值更稳；推理时才手动 softmax。

**Q4. token_type_ids 什么时候用？**
句子对任务(问答/句子关系)，用 0/1 区分句 A / 句 B。单句时全 0。

## 二、微调 / 训练工程（Ch2, 7, 11）

**Q1. 动态填充(DataCollatorWithPadding)比固定 max_length 好在哪？**
动态填充只补到「当前 batch 最长」，而不是全局 max_length。短样本多时能省大量无效计算和显存。

**Q2. 显存不够怎么训大模型？（阶梯）**
梯度累积(小 batch 多步模拟大 batch) → 梯度检查点(用时间换显存，重算激活) → 混合精度(bf16/fp16) → LoRA(只训<1%参数) → QLoRA(基座4bit量化) → DeepSpeed ZeRO(把权重/梯度/优化器状态切到多卡)+offload。

**Q3. 学习率 warmup 为什么需要？linear/cosine 怎么选？**
训练初期参数还很乱，一上来就大学习率容易把模型带崩；先用小学习率热身几步，再升到目标值，更稳。linear 简单够用；cosine 收尾更平滑，大模型/长训练常用。都配前 5-10% warmup。

**Q4. 怎么判断过拟合？怎么解决？**
训练 loss 降但验证 loss 回升、训练/验证准确率差距拉大。解决：正则(weight_decay/dropout)、早停(EarlyStopping)、数据增强/加数据、降模型复杂度。

**Q5. bf16 和 fp16 区别，用哪个？**
都是半精度。bf16 指数位多、动态范围大、不易溢出，更稳(A100/H100 用它)；fp16 精度略高但易上下溢，需配 GradScaler。现代卡优先 bf16。

**Q6. Trainer 和自定义训练循环(Accelerate)怎么选？**
标准微调用 Trainer(封装好日志/评估/保存/多卡/混合精度，代码最少)；需要插自定义逻辑(自定义损失/RL/特殊评估)用 Accelerate 自定义循环(把每步摊开，一套代码单卡/多卡/多机透明切换)。

## 三、分词器（Ch6）

**Q1. BPE / WordPiece / Unigram 区别？各家用哪个？**
都是子词算法。BPE 从小词表合并「最高频」的相邻对(GPT 家族)；WordPiece 合并「得分最高(最黏)」的对(BERT)；Unigram 从大词表删「对损失影响最小」的 token(T5/XLNet)。

**Q2. 为什么用子词，不用整词或纯字符？**
整词→词表爆炸且生僻词全 [UNK]；纯字符→序列太长、丢语义。子词两头折中：常见词整块、生僻词拆成认识的零件。

**Q3. 快速分词器(fast)除了快还有什么用？**
提供 offset 映射和 word_ids，能把 token 级结果对回原文字符位置——NER 贴回原词、QA 还原答案子串，全靠它。

**Q4. 领域词汇(代码/医疗)被切得很碎怎么办？**
在领域语料上重训分词器(train_new_from_iterator 或 tokenizers 库)，让高频术语整块成 token，序列更短=推理更省(实测代码分词器比通用 gpt2 序列缩短约 40%)。

## 四、RAG / 检索（Ch5, 6）

**Q1. 什么是 RAG？为什么需要它？**
检索增强生成：先从知识库按「意思」检索相关文档，再拼进提示喂 LLM 生成回答。解决 LLM 不知道私有/最新知识、会幻觉的问题，且能引用来源、免重新训练模型。

**Q2. 语义检索为什么用向量+余弦，不用关键词？**
关键词只能字面匹配，换个说法就搜不到；把文本嵌成向量后，语义相近的向量也相近，按余弦相似度检索能「按意思找」。归一化后向量点积=余弦，只看方向(语义)不看长度(篇幅)。

**Q3. 句向量为什么要 mean pooling 且用 mask 加权？**
模型输出每个 token 一个向量，要压成一句一个向量。直接平均会把 [PAD] 的废料向量算进去、稀释句向量；用 attention_mask 加权只平均真实 token 才准。

**Q4. 生产 RAG 为什么用向量数据库，不用内存？**
百万~上亿向量内存放不下；向量库用 HNSW/IVF 等近似最近邻索引(ANN)毫秒级检索，还支持增量更新/元数据过滤/持久化/高可用。常用 Milvus/Qdrant/Pinecone/pgvector。

**Q5. 怎么提升 RAG 效果？**
切块策略(200-500token+重叠)、强嵌入模型(bge-m3)、混合检索(向量+BM25关键词，RRF融合)、重排(召回top50→cross-encoder重排取top5)、元数据过滤(按权限/时间)、防幻觉(要求带引用)。

## 五、LoRA / PEFT（Ch11）

**Q1. LoRA 原理？为什么能省这么多？**
冻结原权重，在每层旁插一对低秩小矩阵 A(d×r)、B(r×d)，只训这对(r 很小如8/16)。可训练参数骤降到<1%，梯度和优化器状态也只对这点参数，显存/存储大幅下降；适配器只几 MB，一个基座能挂多个适配器切任务。

**Q2. LoRA 的 r / alpha / target_modules 怎么设？**
r=秩(容量)，常 8/16/32，越大容量越强但省得越少；alpha=缩放，常设 2*r；target_modules 指定给哪些层加，注意力的 q_proj/v_proj 性价比高，要更强就 all-linear。

**Q3. QLoRA 是什么？和 LoRA 区别？**
QLoRA = 基座用 4-bit(NF4)量化加载(省一半以上显存)+ LoRA 只训低秩适配器。让 7B/13B 在单张消费级卡上微调。需要 bitsandbytes(CUDA)。

**Q4. merge_and_unload 干嘛？合并前后取舍？**
把 LoRA 增量并回基座权重，得到一个普通模型，推理零额外开销、可直接部署；但失去「换适配器」的灵活性。单任务上线就 merge，多任务热切换就保留基座+多适配器不 merge。

**Q5. SFT 和继续预训练/RLHF 的区别？**
继续预训练=喂大量领域文本让模型「更懂领域」；SFT=用「指令→理想回复」对教它听指令按格式答；RLHF/GRPO=用偏好/奖励进一步对齐人类偏好。通常 预训练→SFT→RL 三段。

## 六、RLHF / GRPO（Ch12）

**Q1. GRPO 是什么？和 PPO 区别？**
Group Relative Policy Optimization：对同一提示采「一组」答案，用「组内相对好坏」当优势(谁比组内平均好就强化)，不需要单独的价值网络(critic)，比 PPO 简单省显存。DeepSeek-R1 用它训推理能力。

**Q2. GRPO 的优势(advantage)怎么算？**
advantage=(reward-组内均值)/组内标准差。只看「同一题里谁更好」，天然消掉题目难度差异。注意：组内奖励要有方差(有对有错)才有学习信号——全对全错则优势全 0，学不动。

**Q3. 为什么用「可验证奖励」？**
数学/代码/事实题答案能自动验证(对/错、单测通过、能编译)，直接拿正确性当奖励，不用训奖励模型，最可靠。这是 R1 训推理的关键。还常配格式奖励等多个奖励加权。

**Q4. GRPO 生产训练的瓶颈是什么？**
采样(每步对每个提示生成一组补全)最慢，必须用 vLLM 加速；还要同时放策略模型+参考模型+采样，很吃显存，LoRA+多卡是标配。监控 reward(该升)/reward_std(别塌0)/KL(别跑离参考太远崩掉)。

**Q5. KL 惩罚项作用？beta 太大/太小？什么是 reward hacking？**
KL 拉住新策略别离参考模型太远，防为刷奖励而退化。beta 太大=拴太死学不动；太小=容易崩坏。reward hacking=模型钻奖励漏洞刷高分但没真变好；防：正确性占主导、奖励可验证、加 KL、多信号交叉、人工抽检。

## 七、推理 / 部署（Ch1, 3, 9）

**Q1. vLLM 为什么快？两大核心优化？**
①PagedAttention：把 KV Cache 像操作系统分页一样管理，显存碎片少、利用率高 ②Continuous Batching：连续批处理，把不同请求的 token 动态拼在一起算，GPU 不空转。吞吐比原生 transformers 高一个量级。

**Q2. 模型太大放不下怎么部署？**
量化(INT8/INT4，AWQ/GPTQ/FP8)缩小权重；张量并行(把一层切到多卡)；流水线并行；CPU/NVMe offload。vLLM/TGI/TensorRT-LLM 都支持。

**Q3. 生产 LLM 服务架构怎么设计？**
客户端→FastAPI网关(鉴权/限流/日志/路由)→vLLM服务(OpenAI兼容)→GPU。网关和推理引擎解耦；服务无状态、K8s多副本+HPA按GPU利用率自动扩缩；相同prompt结果缓存(Redis)；监控 p99延迟/QPS/GPU利用率。

**Q4. 训练和推理为什么要分离？**
职责/资源不同：训练产出模型→存模型仓库(HF Hub/MLflow/S3)→推理服务从仓库拉取加载。别在一个进程又训又服务，否则没法独立伸缩、更新、回滚。

**Q5. 采样参数 temperature / top_p / top_k 各是什么？**
temperature 调概率分布陡峭度(高=更随机有创意，低=更确定)；top_k 只从概率最高的 k 个里采；top_p(核采样)从累积概率达 p 的最小集合里采。生成任务常 temp=0.7、top_p=0.9；确定性任务 temp=0 贪心。

**Q6. 批处理为什么提速？动态 vs 连续批处理？**
一次算多条，GPU 不空转、吞吐高。静态批处理要等凑满一批；连续批处理(vLLM)每步动态把不同请求的 token 拼一起，新请求随到随进、完成的随时退出，GPU 几乎不空转。

## 八、综合 / 系统设计

**Q1. 给你一个业务(如客服)，怎么从 0 搭一个 LLM 应用？**
①明确任务和评估指标 ②数据(收集/清洗/标注) ③方案选型：能用现成模型+提示/RAG 就别微调；需要格式/领域控制才 SFT+LoRA ④检索(RAG)接私有知识 ⑤评估(离线指标+人工) ⑥部署(vLLM+网关+监控) ⑦上线灰度+持续迭代。

**Q2. 什么时候该微调，什么时候用 RAG/提示词？**
要「新知识/私有知识」→RAG(知识会变，微调追不上)；要「新能力/固定格式/领域风格」→SFT微调；很多场景好的提示词+RAG 就够了，微调是最后手段(贵、易过拟合、知识易过时)。常组合：微调管「怎么答」+RAG 管「答什么」。

**Q3. 怎么评估一个 LLM 系统好不好？**
分任务：分类看准确率/F1；生成看 BLEU/ROUGE + 人工；检索看召回率/命中率；端到端看是否有据(防幻觉)、延迟 p99、成本、用户满意度。线上 A/B + 灰度。

**Q4. 怎么降低推理成本？**
小模型/蒸馏、量化、缓存(相同请求)、批处理(vLLM连续批处理)、把简单请求路由到小模型(模型路由)、限流、KV cache 复用(prefix caching)。

## 九、项目系统设计题（最能体现工程能力，面试常让你「讲一个做过的项目」）

### 文本分类端到端〔案例1〕
- **类别不均衡怎么处理？** ①损失加类别权重(逆频率) ②过/欠采样、WeightedRandomSampler ③换指标(看 F1/PR 而非 acc) ④阈值调整 ⑤收集更多少数类。
- **为什么不能只看准确率？精确率/召回率怎么取舍？** 不均衡时准确率虚高。垃圾邮件宁可漏放(高精确率不误杀)；癌症筛查宁可错报(高召回率不漏诊)。兼顾看 F1；多类看 macro-F1(各类平权)vs weighted-F1(按样本量)。
- **为什么分类用交叉熵不用 MSE？** 交叉熵直接优化「正确类概率」，配 softmax 梯度简洁(pred-target)、不易梯度消失；MSE 用在分类梯度小、收敛慢。

### RAG 语义检索问答〔案例2〕
- **向量+余弦 vs 关键词，各自短板？** 关键词换说法就漏；向量按意思找但对精确术语/编号不敏感 → 生产用混合检索(向量+BM25)+RRF 融合互补。
- **归一化后点积=余弦有什么好处？** 整库一次矩阵乘算完所有相似度，且只看方向(语义)不受篇幅影响。
- **RAG 效果不好怎么系统排查？** 顺链路：切块质量→嵌入是否匹配领域&语言→是否上混合检索/重排→query 改写→top-k 与阈值→提示是否约束据实回答。检索是上限。
- **rerank 为什么提升精度？** 向量是双塔(快但粗)，cross-encoder 把 query+doc 拼一起过模型建模细粒度交互(准但慢)；两阶段：粗召回 top-50→精排 top-5。

### LoRA 指令微调〔案例3〕
- **LoRA 为什么降到 <1%？r/alpha/target_modules？** 冻结 W 只训低秩 A、B；r=容量、alpha=缩放(alpha/r，不改参数量)、target_modules=加到哪些层。
- **因果 LM 为什么把 [PAD] label 设 -100？** 交叉熵 ignore_index=-100 跳过这些位；否则模型学「预测填充」污染梯度。同理 prompt masking 只对 Response 段回传 loss。
- **merge_and_unload 取舍？** 并回基座得普通模型、推理零开销、可部署；但失去换适配器灵活。单任务上线就 merge，多任务热切换不 merge。

### GRPO 强化学习〔案例4〕
- **GRPO vs PPO 为什么更省？** PPO 要额外训 critic 占显存难调；GRPO 用组内相对好坏当优势(基线=组均值)去掉 critic。
- **组内优势怎么算/为什么要有方差？** (reward-组均值)/组标准差；一组全对/全错→方差0→优势≈0→无学习信号，要挑「有对有错」的题。
- **reward hacking 怎么防？** 正确性占主导、奖励尽量可验证、加 KL 约束、多信号交叉、人工抽检、对拒答/空壳单独惩罚。

### 端到端智能客服〔综合大demo〕
- **从 0 搭客服系统？** 定任务指标→先分流(情感/意图分优先级)→RAG 接私有知识→组织回复→置信度分级兜底(拿不准转人工)→部署(单例+网关+监控)→灰度迭代。
- **为什么要置信度分级+转人工兜底？** 模型总给答案但不代表有把握；错误代价远高于转人工。按置信度分级在「自动化率」和「错误率」间权衡。
- **为什么模型不能每请求加载？** 加载=读权重+上 GPU 秒级重操作；每请求加载拖垮延迟、爆显存。启动时加载一次常驻(单例/DI)，服务无状态好扩容。

## 十一、分章高频速问（每章脚本末尾的题，逐条带答，一条不落）

> 这些是各章文件末尾 `面试：` 行里抛出的问题，按章汇总并补上简答。和上面主题库互为「问清单 ↔ 深答案」。

### Ch1 情感分析服务
- **pipeline 内部三步？** 分词器→模型出 logits→后处理(softmax/argmax)。
- **为什么模型只输出 logits？** 训练用的交叉熵内部含 softmax，数值更稳；推理时才手动 softmax。
- **Encoder / Decoder / Encoder-Decoder 各擅长啥？** 分类理解 / 生成对话 / 翻译摘要。

### Ch1 进阶 生成与采样
- **greedy / beam / sampling 各适合什么？** 确定性任务 / 有正确答案的翻译摘要 / 要创造性。
- **top_k 和 top_p 区别？** top_k 固定候选数；top_p(核采样)按累计概率动态截断(更常用)。
- **怎么治复读机？** repetition_penalty(对出现过的词降概率) + no_repeat_ngram_size(硬禁 n-gram 重复)。
- **流式怎么实现？** TextIteratorStreamer + 子线程跑 generate，主线程迭代拿增量。

### Ch2 文本分类微调
- **动态填充比固定 max_length 好在哪？** 只补到当前 batch 最长，省无效计算/显存。
- **Trainer vs 自定义循环怎么选？** 标准微调用 Trainer(封装全)；要插自定义逻辑用 Accelerate 手写循环。
- **compute_metrics 干嘛的？** Trainer 每次评估时把 (logits, labels) 交给它算 acc/F1 等指标。

### Ch3 预训练模型应用
- **MLM 和 CLM 区别？** MLM 双向遮词填空(BERT，理解)；CLM 单向预测下一词(GPT，生成)。
- **AutoModel 和 AutoModelForX 区别？** 前者只出隐藏状态(backbone，做特征/句向量)；后者加了任务头，直接出该任务 logits。
- **怎么用预训练模型取句向量？** 用 AutoModel 出 token 向量 → mean 池化(mask 加权)或取 CLS → 归一化。

### Ch5 语义搜索引擎
- **为什么用向量+余弦不用关键词？** 关键词换说法就漏；向量按语义方向找。
- **句向量为什么 mean 要用 mask？** 不加 mask 会把 [PAD] 废向量算进去稀释句向量。
- **FAISS 解决什么问题？** 大规模向量的近似最近邻(ANN)快速检索。

### Ch5 进阶 数据工程
- **长文超模型长度怎么办？** 切块(chunk)+重叠(stride)，或换长上下文模型；检索场景按 token 滑窗切。
- **stride 重叠为什么重要？** 防止切在语义中间丢上下文，跨边界信息在相邻块都出现，答案不被切断。
- **流式数据集解决什么？** 数据太大装不下时 streaming=True 边下边迭代，不必全量下载/加载。

### Ch6 领域分词器 / 手写算法
- **领域词汇被切碎怎么办？** 在领域语料上重训分词器，让术语整块成 token、序列变短。
- **BPE / WordPiece / Unigram 区别？** 合并最高频对 / 合并得分最高(最黏)对 / 从大词表删损失影响最小的 token。
- **offset_mapping 有什么用？** 把 token 级结果贴回原文字符位置(NER 拼词、QA 还原子串)。
- **三算法训练与编码怎么做？** BPE 训=建 merge 表、编=按表贪心合并；WordPiece 训=按得分合并、编=最长匹配；Unigram 训=EM 迭代删 token、编=维特比选最优切分。
- **WordPiece 打分为什么除以左右频？** score=freq(pair)/(freq(left)×freq(right))，偏好「单独不高频但组合很黏」的对，避免只合并常见字。

### Ch7 NER / 四大任务
- **aggregation_strategy 有什么用？** 把同一实体的多个子词合并成一个实体(simple/first/max/average)。
- **NER 里 -100 标签干嘛的？** 子词非首片/特殊 token 标签设 -100，交叉熵跳过不计损失。
- **子词怎么拼回实体？** 用 word_ids/offset 把连续同类 B-/I- 子词合成完整实体串。
- **抽取式 QA 预测什么？** 答案在原文的起止位置(start/end logits)。
- **困惑度是什么？** PPL=exp(平均交叉熵)，语言模型对文本的「意外程度」，越低越好。
- **BLEU / ROUGE 分别衡量什么？** BLEU 看生成的 n-gram 命中参考(精确率，偏翻译)；ROUGE 看参考被生成覆盖(召回，偏摘要)。
- **seq2seq 的 labels 怎么来？** 目标序列的 input_ids(decoder 预测下一 token)，pad 位设 -100。

### Ch9 Gradio 上线
- **Interface vs Blocks 怎么选？** 快速原型用 Interface(一个 fn+in+out)；复杂布局/联动用 Blocks。
- **Gradio 怎么快速上线/自动出 API？** Interface(...).launch() 自带 REST /api 和 share 链接。
- **gr.State 解决什么？** 每用户独立的多轮会话状态(聊天/计数器/购物车)。
- **流式怎么做？怎么挂到已有 FastAPI？** 函数里 yield 增量；gr.mount_gradio_app(app, demo, path)。

### Ch11 LoRA / 训练工程
- **LoRA 原理？为什么省？** 冻结基座，每层旁插低秩对 A/B 只训这点，参数<1%、显存/存储大降。
- **r / alpha / target_modules 怎么设？** r=容量(8/16/32)、alpha=缩放(常 2r)、target_modules 常给 q/v(要强用 all-linear)。
- **为什么用聊天模板不手拼？** 各家模板不同(ChatML/Llama/Mistral)手拼易错，分词器自带模板还要 add_generation_prompt。
- **Accelerate 解决什么？核心 API？** 一套代码透明支持单卡/多卡/混合精度；prepare(模型/优化器/数据)、backward(loss)、gather。
- **适配器为什么能分离部署？** LoRA 增量是独立小文件，基座只读加载一次、按需挂不同适配器切任务。
- **QLoRA 和 LoRA 区别？** QLoRA 多一步把基座 4-bit(NF4)量化加载，再省一半以上显存。

### Ch12 GRPO
- **GRPO vs PPO？** GRPO 用组内相对优势(基线=组均值)去掉 critic，更简单省显存。
- **优势怎么算？为什么组内要有方差？** (reward-组均值)/组标准差；全对全错方差 0 无学习信号。
- **为什么用可验证奖励？** 数学/代码/事实能自动判对错，直接拿正确性当奖励最可靠，不用训奖励模型。
- **多奖励怎么组合？** 正确性为主 + 格式奖励(逼出推理)+长度/简洁奖励等，加权求和。

### 中文版（模型选型）
- **为什么不能用英文模型跑中文？** 模型只认训练过的语种/词表，跨语言失准。
- **中文检索为什么不用英文嵌入？** 语义空间不对齐，要用 bge/text2vec 等中文嵌入。
- **中文 NER 和英文不同在哪？** 常逐字标注要拼回词、类型体系不同(CLUENER 10 类)。
- **做中文 NLP 系统模型怎么选？** 情感→中文点评微调；检索→bge-zh/text2vec；NER→CLUENER/UIE；生成→Qwen/GLM。

### Agent
- **怎么把已有模型能力接进 Agent？Agent 靠什么决定调哪个工具？** 包成工具；靠工具的 name+description+参数类型。
- **Agentic RAG 和普通 RAG 区别？** 普通固定检索一次；Agentic 让 LLM 自己决定查什么/查几次/够不够。
- **Agent 为什么要用 MCP？** 工具即插即用/热插拔、跨进程跨团队复用。
- **三框架怎么选？** 快速/代码任务→smolagents；复杂可控流程→LangGraph；数据 RAG 重→LlamaIndex。

### MCP（协议进阶）
- **能力协商为什么取交集？通知和请求怎么区分？** 双方只用都支持的能力；通知无 id 不需响应，请求有 id 要响应。
- **Roots / Sampling 方向和普通调用有何不同？** 普通是 client→server；Roots/Sampling 是 server→client 反向。
- **FastMCP 和手写 JSON-RPC 关系？** 同一套 MCP 消息，FastMCP 用装饰器自动生成 schema/传输。
- **Gradio 怎么一键成 MCP 服务器？生产里 Host 怎么连？** launch(mcp_server=True)；用官方 SDK Client 不手写 subprocess。
